# sattva-life БАЗА ЗНАНИЙ
## о простой жизни и возвышенном мышлении

## О проекте

Цель этого проекта создавать базу знаний о преданном служении, варнашраме и простой жизни в сельских вайшнавских поселениях. Приглашаю, всех желающих принять участие в наполнении и улучшении этой базы. 
Вы можете самостоятельно писать и добавлять материалы, можете помогать присылая полезнык маткериалы или сообщать нам об ошибках и недочетах
В качестве хранилища для базы знаний выбран github, технология для публикации - MKDocs (язык программирования Python). Но все может также работать даже без github и pyhon, офллан и легко переносится между компьютерами.
Для хранения базы знания не требуется специального хостинга, не нужно даже оплачивать доменное имя - все работает практически независимо. 
На данный момент я оплачиваю доменное имя sattvalife.ru, но если оно будет утрачено, то сайт все равно будет доступен по адресу https://iskcon-developers-community.github.io/sattva-life/
Также вы можете просматривать материалы или скачать сайт полностью на свой компьютера из github репозитория здесь https://github.com/ISKCON-developers-community/sattva-life
